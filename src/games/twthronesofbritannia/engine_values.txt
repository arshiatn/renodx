==============================================================================================

Each is a named value the game keeps in memory and its code reads (values nothing reads are left out).
Game: its built-in value
(bools are set at run time: not listed). In the mod: a RenoDX slider or switch changes it (Graphics 2 of 2).
Most are read when a battle or the campaign loads. Changing some may break the game or crash it.
